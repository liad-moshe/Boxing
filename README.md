# Boxing

A 3D boxing game built in **Godot 4.7.2 (.NET) with C#**. Everything you see and hear is generated by
code, with no external assets.

The game is made by a virtual studio of Claude Code agents (Producer, designer, boxing consultant,
developer, QA, knowledge-base keeper, and later a tech artist). The human owner is the client: they give
direction, playtest builds and approve every change on GitHub.
