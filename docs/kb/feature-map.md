# Feature map

Maps each player-facing feature to the code, scenes, inputs and tests behind it, so any agent can find
the right place to change. Maintained by kb-keeper. Rules: no line numbers; every backticked repo path
must exist (CI kb-check).

| Feature | Player-facing behaviour | Code anchors (`path` + `Type.Member`) | Scenes | Inputs | Tests |
|---|---|---|---|---|---|
| Main menu | Launch shows a "Boxing" title with New Game (selected first) and Exit. Up/Down wrap; mouse hover selects; Enter or left-click activates. New Game clears the picks and opens Character Select; Exit quits | `src/Core/MenuSelection.cs` + `MenuSelection.MoveUp`, `MenuSelection.MoveDown`, `MenuSelection.Hover`; `game/scripts/Menu.cs` + `Menu._Ready` (builds the controls), `Menu._UnhandledInput` (keys), `Menu.Activate` (New Game or Exit) | `game/scenes/Menu.tscn` (main scene in project.godot) | menu_up; menu_down; menu_confirm | `tests/Core.Tests/MenuSelectionTests.cs`; `game/scenes/smoke/Smoke.cs` + `Smoke._Ready` (checks the menu builds with its two buttons); `game/scenes/smoke/Smoke.tscn` (headless smoke) |
| Character select | After New Game: step 1 "Choose your boxer", then step 2 "Choose your opponent", then the ring. Two cards side by side, each with name, archetype and six stat bars with numbers (display only, no gameplay effect). Left/Right move the single highlight and wrap; mouse hover highlights; Enter or left-click confirms. Step 2 shows "You: <name>" and a YOU tag on the player's pick. Same boxer for both is allowed. Escape steps back one level | `src/Core/CharacterSelectFlow.cs` + `CharacterSelectFlow.Confirm`, `CharacterSelectFlow.Back`; `src/Core/MenuSelection.cs` + `MenuSelection.MoveUp`, `MenuSelection.MoveDown`, `MenuSelection.Hover`; `game/scripts/CharacterSelect.cs` + `CharacterSelect._Ready` (builds the screen), `CharacterSelect._UnhandledInput` (keys), `CharacterSelect.Confirm` (advances step, or stores picks and changes to the ring), `CharacterSelect.GoBack` (step back or to the menu), `CharacterSelect.OnHover`, `CharacterSelect.OnCardInput` (mouse) | `game/scenes/CharacterSelect.tscn` | menu_left; menu_right; menu_confirm; ui_back | `tests/Core.Tests/CharacterSelectFlowTests.cs`; `tests/Core.Tests/MenuSelectionTests.cs`; `game/scenes/smoke/Smoke.cs` + `Smoke._Ready` (checks the select screen builds its two cards); `game/scenes/smoke/Smoke.tscn`; the rest is manual (playtest) |
| Fighter roster | Two boxers, in file order on screen: Bruno "The Anvil" Kessler (Slugger) and Mateo "Ghost" Rivera (Out-boxer). Six stats each, 1 to statMax, equal totals. Stats are display-only. Data is in `data/balance/fighters.json`: each look sets colours, hair style (buzz or short) and build scales; the shared body sets proportions, guard pose and face colours | `src/Core/FighterRoster.cs` + `FighterRoster.Parse` (validates and throws RosterException), `FighterRoster.IndexOf`, `FighterRoster.FindOrFirst`, `FighterRoster.DefaultHighlightIndex`, `FighterBody.RequiredNumbers`; `src/Core/GuardPose.cs` + `HairStyles.CapScale`; `game/scripts/GameSession.cs` + `GameSession.Roster` (reads the file) | — | — | `tests/Core.Tests/FighterRosterTests.cs` |
| Game session (picks hand-off) | Holds the player's and the opponent's boxer from select to ring. Cleared on New Game, on Escape back to the menu, and when select starts. With no picks, the ring uses the first roster entry for both | `game/scripts/GameSession.cs` + `GameSession.Clear`, `GameSession.PlayerId`, `GameSession.OpponentId`; `game/scripts/Main.cs` + `Main._Ready` (falls back to the first entry through `FighterRoster.FindOrFirst`) | — | — | `game/scenes/smoke/Smoke.cs` + `Smoke._PhysicsProcess` (checks the ring has two fighters, direct launch) |
| Fighter build (ring) | Each fighter is a standing human boxer built from primitives: head with hair cap, eyes, nose and mouth on the side facing the opponent, neck, shoulders, tapered torso, shorts with a waistband, two legs with feet, two arms bent up in a guard with large gloves in front of the face. Skin, hair, trunks, waistband, glove and eye colours, hair style and build scales come from the boxer's look; proportions and guard pose come from the shared body data. A "YOU" or "CPU" label floats above each. Player on the left (facing right), CPU on the right (facing left) | `game/scripts/FighterBuilder.cs` + `FighterBuilder.Build`; `src/Core/GuardPose.cs` + `GuardPose.Solve`; `game/scripts/Main.cs` + `Main._Ready` (places them at the roster's player and opponent X) | `game/scenes/Main.tscn` | — | `tests/Core.Tests/GuardPoseTests.cs`; `game/scenes/smoke/Smoke.cs` + `Smoke.CheckLook` (checks parts, colours, guard pose, face side and Anvil/Ghost build order; run from `Smoke._PhysicsProcess`); `game/scenes/smoke/Smoke.tscn` |
| Escape back (screen flow) | Ring: Escape returns to the menu and clears the picks; the game stays open. Select step 2: Escape returns to step 1 with the player's pick highlighted. Select step 1: Escape returns to the menu. A held Escape counts once. Escape never quits from the ring or select | `src/Core/ScreenFlow.cs` + `ScreenFlow.OnBack` (Ring and CharacterSelect answer GoToMenu; the CharacterSelect answer is not called by game code, which uses `CharacterSelectFlow.Back`); `src/Core/CharacterSelectFlow.cs` + `CharacterSelectFlow.Back`; `game/scripts/CharacterSelect.cs` + `CharacterSelect.GoBack`; `game/scripts/Main.cs` + `Main._UnhandledInput` (performs the scene change to the menu) | `game/scenes/Main.tscn`; `game/scenes/Menu.tscn`; `game/scenes/CharacterSelect.tscn` | ui_back | `tests/Core.Tests/ScreenFlowTests.cs`; `tests/Core.Tests/CharacterSelectFlowTests.cs`; ring-to-menu and select scene changes are manual (playtest), not in smoke |
| Quit game | The Exit item quits.
