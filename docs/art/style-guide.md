# Art & audio style guide

> **M2 placeholder.** The tech-artist fills this in during milestone M2 ("Look & Feel"). Until then M1
> uses flat colours on primitive shapes.

## The no-external-assets rule (applies from day one)
- All visuals and audio are generated by code:
  - primitives and CSG,
  - ArrayMesh / SurfaceTool,
  - `.gdshader` shaders,
  - procedural textures (NoiseTexture2D, GradientTexture2D),
  - procedural audio (AudioStreamGenerator).
- Never download or commit images, models, fonts or sounds.
- **The one exception:** small, client-approved capture PNGs in `docs/art/approved/` (M2+). These are
  screenshots used as visual reference. The game never loads them.

## To be defined in M2
- Palette and lighting mood.
- Boxer silhouette and proportions.
- Ring and venue look.
- HUD typography, using the engine's default font, since font files are external assets.
- Sound palette: impacts, bell, crowd.
